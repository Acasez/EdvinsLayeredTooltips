Edvin's Nested Tooltips is exactly what it sounds like, it's a Unity Asset that helps easily add nested tooltips. Perfect for strategy games, rpg's or just any game with many mechanics and subsystems.  It's inspired by systems seen in games like Crusader King 3 and Baldurs Gate 3.

You can set up any amount of keywords, with no restriction on keyword length or variations. Keywords can have an icon, and a tooltip on their own which allows players to easily connect gameplay elements without having to visit wikis or look things up.

I have written more about the development of the tool on my website here: https://acasez.github.io/edvinsNestedTooltips
